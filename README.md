# Nova Roleplay — Downloads oficiais

Este repositório publica as versões oficiais do APK Nova Roleplay usadas pelo launcher.

- O arquivo `version.json` contém a versão, o tamanho e o SHA-256 esperados.
- Os APKs ficam exclusivamente em **Releases**, fora do histórico Git.
- O launcher valida package, `versionCode`, tamanho e SHA-256 antes de abrir o instalador Android.

Não envie senhas, tokens, banco de dados, logs de jogadores ou chaves de assinatura para este repositório.
